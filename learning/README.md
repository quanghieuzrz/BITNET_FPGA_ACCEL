# learning/

Các script học từng bước (không dùng trong golden model chính thức). Chạy độc lập:

| File | Nội dung |
|---|---|
| `buoc1_mot_hang.py` | 1 hàng W × X bằng cộng/trừ |
| `buoc2_chuan_hoa.py` | Chuẩn hoá Acc về INT8 |
| `buoc3_chia_khuc.py` | Nhiều hàng, chia khúc 64, nhóm 4 làn |
| `buoc4_ma_hoa_x.py` | Mã hoá X thành beat 512 bit |
| `buoc5_ma_hoa_w_v1.py` | Mã hoá W v1 (2 bit) thành beat |
